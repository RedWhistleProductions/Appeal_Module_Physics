Physics Module

Appeal docsModule standardBasicAdvancedGlobals

Script functions provided by the Physics module. Prefix each call with Physics; arguments below are consumed in the listed order. Plugin support and behavior may vary.

Basic covers ordinary application and game operations. Advanced covers explicit setup, backend management, and tuning. This classification describes the current API; it does not certify that every backend yet provides the complete Basic-only game workflow required by the standard.


Basic functions

FunctionArgumentsDescription
UseEntity: string, Plugin_Name: stringRequests the module to use.
AttachEntity: string, Plugin_Name: stringRequests the module to attach. Alias of Use.
ReleaseEntity: stringRequests the module to release.
DetachEntity: stringRequests the module to detach. Alias of Release.
UpdateEntity: stringAdvances or refreshes the module state for the current update cycle.
Set_PositionEntity: string, X: float, Y: float, Z: floatRequests the module to set position.
Set_VelocityEntity: string, X: float, Y: float, Z: floatRequests the module to set velocity. Alias of Set_Position.
Apply_ForceEntity: string, X: float, Y: float, Z: floatRequests the module to apply force. Alias of Set_Position.
Apply_ImpulseEntity: string, X: float, Y: float, Z: floatRequests the module to apply impulse. Alias of Set_Position.

Globals

This module does not publish script-visible globals in its current module bridge. Plugin internals and C++ variables are not Appeal globals.

Reference source: module interpreter. Required arguments are not optional defaults. Advanced setup may be performed by Appeal configuration before a Basic script runs.
